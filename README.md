# 日文修行帳

一個給「無壓力學日文 with yuma」聽眾用的每日學習記錄 + 複習系統。單一檔案的網頁 App（`index.html`），沒有建置流程。

聽眾頁面：https://open.spotify.com/show/1yO2RxQfkatCyI8lzRWOBe

## 功能

- **今日紀錄**：記下今天聽到的單字、文法、集數與心得，可挑選公開的集數標題快速帶入（僅供參考，不是逐字稿）。
- **回顧**：依日期瀏覽過去所有紀錄，可用關鍵字搜尋單字、文法或筆記。
- **單字卡**：每天新增的單字/文法會自動變成單字卡，用簡化版 SM-2 間隔重複演算法排定複習時間；也可以直接在列表裡編輯、重設進度或刪除。
- **小測驗**：選擇題或打字題兩種模式，打字題會先自動比對答案，答錯時可以自己判斷「其實答對了」再繼續，答題結果會回饋到單字卡的複習排程。
- **統計**：連續學習天數、最長紀錄、單字卡數量、近 12 週的學習熱力圖等。

## 資料存放

這個 App 在 Claude Artifact 環境中執行時，會使用 Claude 的 `db` capability 把資料存在雲端，同一個網址在手機、電腦上打開都會同步。如果不是在 Claude Artifact 裡開啟（例如直接把 `index.html` 用瀏覽器打開，或部署到自己的網站），會自動改用瀏覽器的 `localStorage`，資料只存在那個瀏覽器裡，記得用「匯出」功能備份。

## 使用方式

最簡單的方式是直接用 Claude 幫你發布成 Artifact，拿到一個網址；在手機瀏覽器打開後可以「加入主畫面」，用起來很接近一個 App，不需要另外部署或寫程式。

若想自架網站（例如 GitHub Pages），把 `index.html` 直接部署即可，但此時 `db` capability 無法使用，資料只會存在本機瀏覽器的 `localStorage`。
